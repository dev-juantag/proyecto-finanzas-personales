# Contador Personal 💵

Contador Personal es una aplicación web moderna diseñada para ayudarte a gestionar tus finanzas personales de manera sencilla y eficiente.

## Características Principales

- **Dashboard Interactivo**: Visualiza un resumen rápido de tus cuentas, ingresos y gastos.
- **Gráficos en Tiempo Real**: Estadísticas detalladas de tus flujos de caja y distribuciones por categorías.
- **Control de Presupuestos**: Define límites mensuales por categoría y recibe alertas visuales.
- **Transacciones**: Registro, paginación y categorización de cada movimiento.
- **Diseño Moderno**: Interfaz con soporte para modo oscuro y colores atractivos usando Tailwind CSS.

## Tecnologías Utilizadas

- **Frontend**: Next.js 14+ (App Router), React, Tailwind CSS, Lucide Icons, Recharts.
- **Backend & DB**: Prisma ORM, Supabase (PostgreSQL).
- **Autenticación**: NextAuth.js (Credentials).
- **Estado**: Zustand.
